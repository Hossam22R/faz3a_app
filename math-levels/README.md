**المرجع المنهجي:** دليل IES لمساعدة المتعثّرين في الرياضيات (2021): تعليم صريح منظّم، تمثيلات بصرية وخط الأعداد، أنشطة طلاقة موقوتة، مسائل لفظية، مراجعة تراكمية؛ مع التدرّج المحسوس ← المصوّر ← المجرّد، والإدراك السريع للكمية، ونموذج الأشرطة.

**البناء:** يعتمد على `../arabic-reading-levels` (الخطوط والقوالب). `node src/m1.js && node src/cover.js`

## قرار المستخدم
- «لا يحتاج مطابقة، عملنا أن نجد حلولاً للمتلكئين»: لا نطابق على كتب الوزارة؛ المرجع هو أبحاث علاج الضعف والفجوات الشائعة.
