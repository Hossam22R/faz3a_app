# كتاب تلوين Happy Animals — جاهز للنشر على Amazon KDP

كتاب تلوين للأطفال من 3 إلى 8 سنوات، فيه 30 حيواناً لطيفاً مرسوماً برسوم متجهية (vector) بخطوط سميكة. كل الرسومات أصلية ومولَّدة بالكود، فهي حادة عند أي دقة طباعة.

## الملفات الجاهزة (مجلد `output/`)
| الملف | الاستخدام |
|---|---|
| `interior.pdf` | الصفحات الداخلية: 68 صفحة بمقاس 8.5×11 إنش، بلا حواف نزف (No bleed) |
| `cover.pdf` | الغلاف الكامل بمقاس 17.4031×11.25 إنش: ظهر + كعب 0.1531 إنش + واجهة، مع نزف 0.125 إنش |
| `cover-front.png` | الواجهة وحدها، للإعلانات ووسائل التواصل |
| `cover-full-preview.png` | معاينة الغلاف كاملاً |
| `listing-colored-samples.png` / `listing-page-samples.png` | صور عيّنات للتسويق وصفحة المنتج |
| `listing.md` | العنوان والوصف والكلمات المفتاحية والتصنيفات (بالإنجليزية) |

## محتوى الكتاب
1. صفحة العنوان
2. صفحة حقوق النشر
3. صفحة "هذا الكتاب ملك لـ"
4. صفحة "جرّب ألوانك"
5. 30 صفحة تلوين، كل صفحة مطبوعة على وجه واحد وخلفها صفحة فارغة حتى لا يتسرب لون الأقلام
6. شهادة "Great Job!" في نهاية الكتاب

## قبل الرفع (مهم)
1. ضع اسمك بدل `Your Name` في `src/config.js`، ثم أعد البناء (الطريقة في الأسفل).
2. ابحث في أمازون عن عنوان "Happy Animals Coloring Book". إن وجدته مستخدماً بكثرة فغيّره في `config.js` وفي `listing.md`.
3. **إفصاح الذكاء الاصطناعي:** الرسومات صُنعت بمساعدة الذكاء الاصطناعي (كتبه Claude بالكود). نصيحتي أن تجيب "نعم" على سؤال المحتوى المولّد بالذكاء الاصطناعي في KDP، فهذا أسلم.
4. السعر: لم أحدده لأني لا أعرف الأسعار الحالية. استعمل حاسبة الأسعار في KDP وقارن بالكتب المنافسة.

## خطوات الرفع على KDP
1. افتح kdp.amazon.com، ثم اختر Create، ثم Paperback.
2. انسخ البيانات من `listing.md`.
3. اختر الطباعة بالأبيض والأسود على ورق أبيض، والمقاس 8.5×11، وبلا نزف.
4. ارفع `interior.pdf` في خانة Manuscript، و`cover.pdf` في خانة Cover (اختر "Upload a cover you already have").
5. افتح Print Previewer وراجع الصفحات، ثم اطلب نسخة تجريبية مطبوعة (Proof copy) قبل النشر.

## إعادة البناء بعد أي تعديل
```bash
npm install && pip install pymupdf pillow
src/make.sh
```
يستعمل البناء متصفح Chromium عبر Playwright.

## هيكل الكود
- `src/lib.js`: مكتبة الرسم (الوجه اللطيف، الغيوم، الأزهار، الأمواج...)
- `src/animals1-3.js`: الحيوانات الثلاثون
- `src/page.js`: قالب صفحة التلوين
- `src/build.js`: بناء ملف الصفحات الداخلية والغلاف
- `src/preview.js`: معاينة سريعة (`node src/preview.js color`)
