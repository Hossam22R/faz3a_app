# Read English with Confidence · أقرأ الإنكليزيّة بثقة

سلسلة علاج الضعف في الإنكليزيّة للطفل العربيّ (٤ مستويات)، تصميم ملوّن، صفحات من اليسار إلى اليمين، تعليمات إنكليزيّة مع ترجمة عربيّة.

| الملف | المحتوى |
|---|---|
| `output/english1-interior.pdf` | المستوى ١ «Letters & Sounds» (٩٦ ص): ٢٦ حرفاً بترتيب SATPIN، صفحتان لكل حرف، دمج بالأزرار الصوتية، صفحات p/b و v/f و b d p q، مراجعات، تحدّي التفكير، ألعاب وتلوين، تشخيص وشهادة |
| `output/english1-cover.pdf` / `-back-cover.pdf` | الغلاف وظهره |

المرجع: الصوتيات المنهجية (NRP 2000، Rose 2006). الخطوط: Andika (مصمم لتعليم القراءة، a و g بشكل الكتابة اليدوية)، Fredoka، Cairo.
بناء: `node src/e1.js && node src/cover.js` (يعتمد على `../arabic-reading-levels` و`../math-levels`).
