# سلسلة «أقرأ بثقة» — علاج الضعف القرائي

أربعة كتب للتلاميذ المتلكّئين في القراءة العربية (من الصف الثاني إلى الرابع الابتدائي)، للطباعة في مطبعة مؤسسة وصال التعليمية.

| الملف | المحتوى |
|---|---|
| `output/level1-interior.pdf` | المستوى ١ (١٢٠ ص): الحروف بالحركات القصيرة + تخطيط وتلوين لكل حرف + دمج + إملاء + كلمات قرآنية + الفاتحة |
| `output/level2-interior.pdf` | المستوى ٢ (١٠٤ ص): ١٢ وحدة + سورة لكل وحدة + إملاء + تخطيط + قراءات + تلوين + بطاقات |
| `output/level3-interior.pdf` | المستوى ٣ (٩٦ ص): الجملة + ٢٠ نصّاً + ١٠ سور قصيرة + إملاء + خطّ + تلوين + قاموس مصوّر |
| `output/level4-interior.pdf` | المستوى ٤ (٩٢ ص): أقرأ وأكتب بلا أخطاء — ١٠ دروس إملائية (الهمزات، التاء، الألف الليّنة، «ال»، التنوين، الحروف المتقاربة) + ١٠ نصوص للطلاقة + ١٠ سور |
| `output/level{1,2,3,4}-cover.pdf` و`-back-cover.pdf` | الأغلفة بمقاس 216×303 مم (A4 مع قص زائد ٣ مم) |

الداخل A4 بالأبيض والأسود، بلا قص زائد. عدد الصفحات من مضاعفات ٤.

**البناء:** `npm install && pip install pymupdf pillow && src/make.sh`
(يعتمد على مكتبة الرسوم في `../kdp-coloring-book`).

كل صفحة محميّة بإطار «مؤسسة وصال التعليمية – جميع الحقوق محفوظة» وعلامة مائية خفيفة. الخطوط: Cairo وAmiri Quran (مجلد `fonts/`، رخصة OFL). النص القرآني من حزمة quran-json (الرسم العثماني).
