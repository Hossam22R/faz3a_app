# سلسلة «أقرأ بثقة» — علاج الضعف القرائي

ثلاثة كتب للتلاميذ المتلكّئين في القراءة العربية (من الصف الثاني إلى الرابع الابتدائي)، للطباعة في مطبعة مؤسسة وصال التعليمية.

| الملف | المحتوى |
|---|---|
| `output/level1-interior.pdf` | المستوى ١ (٦٨ ص): الحروف بالحركات القصيرة، مرتّبة في عائلات الشكل |
| `output/level2-interior.pdf` | المستوى ٢ (٦٠ ص): المدود، السكون، التنوين، الشدّة، ة/ه، اللام القمرية والشمسية |
| `output/level3-interior.pdf` | المستوى ٣ (٦٠ ص): الجملة + ٢٠ نصّاً مشكولاً مع أسئلة فهم وقياس طلاقة |
| `output/level{1,2,3}-cover.pdf` | الأغلفة بمقاس 216×303 مم (A4 مع قص زائد ٣ مم) |

الداخل A4 بالأبيض والأسود، بلا قص زائد. عدد الصفحات من مضاعفات ٤.

**البناء:** `npm install && pip install pymupdf pillow && src/make.sh`
(يعتمد على مكتبة الرسوم في `../kdp-coloring-book`).
